## Overview

Phosphor models the ring modulator, voltage-controlled filter bank, and spatial chorus from the rare EMS Synthi 100, recreating the cold, metallic timbres of early electronic music institutions.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Audio Damage Phosphor** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Ring Modulator** | Accurate simulation of the Synthi 100 balanced ring modulator circuit |
| **Filter Bank** | Six-band voltage-controlled bandpass filter bank with resonance |
| **Spatial Chorus** | Triple bucket-brigade chorus with independent rate and depth per voice |
| **Noise Source** | White and pink noise sources matching original circuit noise floor |
